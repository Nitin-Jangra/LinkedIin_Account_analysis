# 📈 LinkedIn Account Growth Analysis

---

## 🧠 Overview
This project provides a **comprehensive analysis of LinkedIn account growth** over time.  
It focuses on metrics like **Impressions**, **Engagements**, and **Post Performance** to uncover insights about:
- Audience behavior  
- The impact of posting frequency  
- The relationship between content and engagement  

The analysis uses Python’s data analysis and visualization libraries to explore, clean, and visualize multiple datasets representing LinkedIn post data.

---

 🚀 Key Features
- 📊 **Dataset Integration** – Merges and analyzes multiple LinkedIn performance files (CSV, Excel).  
- 📈 **Engagement Analysis** – Computes total and average engagement metrics.  
- 👁️ **Impression Insights** – Evaluates reach, frequency, and visibility patterns.  
- 🗓️ **Date Conversion** – Cleans Excel serial date formats into readable dates.  
- 📅 **Growth Tracking** – Tracks engagement and impressions over time.  
- 🎨 **Data Visualization** – Creates beautiful and insightful charts using Matplotlib and Seaborn.
